# OTPbank Mobile App Concept

Этот проект представляет концепцию новой витрины мобильного приложения OTP Bank. Цель — улучшить пользовательский опыт, повысить вовлеченность и конверсию за счет персонализированной витрины и сценариев жизни пользователей.

> ⚠️ Важно: на текущем этапе реализован **только визуальный прототип**. Основной функционал приложения (логика, интеграции, базы данных) ещё не разработан.

## Основные возможности визуального прототипа

- Персонализированная главная витрина
- Разделы по жизненным сценариям
- Визуальное отображение продуктов банка внутри сценариев
- Элементы финансового помощника

## Цели проекта

- Упростить навигацию для пользователей
- Сделать интерфейс более интуитивным
- Визуализировать концепцию персонализации

## Дальнейшие шаги

- Разработка функционала приложения
- Интеграция с банковскими сервисами
- Тестирование пользовательского опыта
- Доработка визуального прототипа на основе фидбэка

---
Запуск:

  в OTPbank project\vite.config.ts ввести allowedHosts - ваш домен (localhost будет работать без него)
  ```bash
  cd "в папку проекта"
  npm install
  npm run dev
  ```
    
Проект находится на стадии **proof-of-concept**. Визуальная часть готова для презентации и обсуждения, функциональная реализация планируется на следующих этапах.
